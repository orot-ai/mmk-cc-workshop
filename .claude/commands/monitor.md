YouTube AI 콘텐츠 모니터링을 실행합니다. 아래 단계를 순서대로 수행하세요.

## 1단계: 새 영상 확인
`python3 scripts/fetch_new_videos.py` 를 실행하여 새 영상 목록을 가져옵니다.

- 결과가 빈 배열(`[]`)이면 "새로운 AI 관련 영상이 없습니다."를 출력하고 종료합니다.
- 영상이 있으면 각 영상에 대해 2~5단계를 반복합니다.

## 2단계: 자막 추출 및 요약
각 영상에 대해:
1. `mmk youtube transcript <url>` 실행하여 자막을 가져옵니다
2. 자막 내용을 한국어로 요약합니다:
   - 한줄 요약 (1문장)
   - 핵심 포인트 (3~5개 불릿)
   - 주요 키워드

## 3단계: 슬랙 알림
Slack MCP의 `slack_send_message`를 사용하여 채널 ID `C0ARSJH030S` (#정보받기)에 메시지를 보냅니다.

메시지 포맷:
```
*[채널명] 새 영상 요약*

*제목:* 영상 제목
*링크:* 영상 URL

*한줄 요약:* ...

*핵심 포인트:*
• 포인트 1
• 포인트 2
• 포인트 3

*키워드:* #키워드1 #키워드2
```

## 4단계: 노션 저장
Notion MCP의 `notion_create_pages`를 사용하여 `config/channels.json`의 `notion_database_id`에 해당하는 DB에 페이지를 생성합니다. config 파일에서 notion_database_id를 읽어서 사용하세요.

속성:
- 제목: 영상 제목
- 채널: 채널명
- 요약: 한줄 요약 + 핵심 포인트
- URL: 영상 링크
- 게시일: 영상 게시일
- 키워드: 매칭된 키워드들

## 5단계: 처리 완료 기록
각 영상 처리가 끝나면 `python3 scripts/fetch_new_videos.py --mark-processed <video_id>`를 실행하여 중복 처리를 방지합니다.

## 완료
모든 영상 처리가 끝나면 처리된 영상 수와 간단한 요약을 출력합니다.
