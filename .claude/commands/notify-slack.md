영상 요약을 슬랙 #정보받기 채널에 발송합니다.

## 입력
$ARGUMENTS 에 아래 형식의 데이터가 전달됩니다:
- 제목, 채널명, URL, 요약 내용, 키워드

## 실행
Slack MCP의 `slack_send_message` 도구를 사용하여 채널 ID `C0ARSJH030S` (#정보받기)에 메시지를 보냅니다.

## 메시지 포맷
```
*[채널명] 새 영상 요약*

*제목:* 영상 제목
*링크:* 영상 URL

*한줄 요약:* 요약 내용

*핵심 포인트:*
• 포인트 1
• 포인트 2
• 포인트 3

*키워드:* #키워드1 #키워드2
```

메시지 발송 후 성공/실패 결과를 출력합니다.
