YouTube 영상의 자막을 추출하고 요약합니다.

## 입력
$ARGUMENTS 에 YouTube URL이 전달됩니다.

## 실행 단계

### 1. 메타데이터 조회
`mmk youtube metadata $ARGUMENTS` 를 실행하여 영상 정보를 가져옵니다.

### 2. 자막 추출
`mmk youtube transcript $ARGUMENTS` 를 실행하여 자막을 가져옵니다.

자막 추출이 실패하면 사용자에게 알리고 종료합니다.

### 3. 요약 생성
자막 내용을 분석하여 한국어로 요약합니다:

**출력 포맷:**
```
## 영상 요약

**제목:** [영상 제목]
**채널:** [채널명]
**게시일:** [날짜]

### 한줄 요약
[1문장으로 핵심 내용 요약]

### 핵심 포인트
- [포인트 1]
- [포인트 2]
- [포인트 3]
- [포인트 4 (필요시)]
- [포인트 5 (필요시)]

### 주요 키워드
#키워드1 #키워드2 #키워드3
```
